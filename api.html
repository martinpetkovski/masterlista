ТопЛиста.мк API v1

Преглед

Јавен REST API за пристап до податоците на ТопЛиста.мк. Сите одговори се во JSON формат. Не е потребна автентикација.

Базен URL: https://toplista-api.deeeeelay.workers.dev/api/v1

  • Формат: JSON
  • Метод: Само GET
  • Лимит: 60 барања/минута по IP
  • Кеширање: Одговорите се кешираат 5 минути
  • CORS: Вклучен за сите домени

Пагинација

Ендпоинтите кои враќаат листи поддржуваат пагинација:

ПараметарОписСтандардно
limitМаксимален број резултати (1–200)50
offsetПочетна позиција0

Одговорот содржи total, limit, offset и data (низата со резултати).

Артисти

GET /api/v1/artists
Листа на артисти од базата, со филтрирање и пребарување.
ПараметарОпис
qПребарување (по име, град, жанр)
cityФилтер по град (пр. Скопје)
genreФилтер по жанр (пр. Rock)
confirmedtrue или false — верифицирани артисти
// Пример: сите артисти од Битола со жанр Rock GET /api/v1/artists?city=Битола&genre=Rock // Одговор: { "total": 3, "limit": 50, "offset": 0, "data": [ { "name": "100REN", "city": "Битола", "genre": "Alternative Rock, Hardcore", "links": { ... }, "confirmed": true, "image": "https://..." } ] }
GET /api/v1/artists/:slug
Поединечен артист по slug (транслитерирано име).
// Пример: артист „Мизар" → slug „mizar" GET /api/v1/artists/mizar // Одговор: { "name": "Мизар", "city": "Скопје", "genre": "Progressive Rock", "links": { "spotify": "...", "youtube": "..." }, "confirmed": true, "image": "https://..." }

Настани

GET /api/v1/events
Листа на настани, со филтрирање по датум и артист.
ПараметарОпис
fromПочетен датум (пр. 2026-01-01)
toКраен датум
artistФилтер по артист
upcomingtrue — само идни настани
// Пример: идни настани GET /api/v1/events?upcoming=true // Одговор: { "total": 12, "limit": 50, "offset": 0, "data": [ { "id": "evt-20260801-...", "title": "Расплет Фест Ден 1", "date": "2025-08-01", "time": "19:00", "place": "Споменик на слободата, Кочани", "artists": ["Корка", "Алембик"] } ] }

Изданија

GET /api/v1/releases
Изданија (синглови и албуми) од Spotify, со YouTube прегледи.
ПараметарОпис
artistФилтер по артист (име на кирилица или латиница)
typesingle или album
fromПочетен датум на издавање
toКраен датум на издавање
// Пример: нови синглови од април 2026 GET /api/v1/releases?type=single&from=2026-04-01 // Одговор: { "total": 15, "limit": 50, "offset": 0, "data": [ { "bandName": "Мизар", "releaseTitle": "Vardar e Stiks", "releaseType": "single", "releaseDate": "2026-04-07", "thumbnail": "https://...", "trackNames": ["Vardar e Stiks"] } ] }

Жанрови

GET /api/v1/genres
Листа на сите жанрови во базата.
GET /api/v1/genres // Одговор: низа од жанрови ["Acoustic", "Alternative", "Alternative Rock", "Blues", ...]

Топ Листа

GET /api/v1/chart
Тековна топ листа — податоци за рангирање (популарност, прегледи, следбеници).
GET /api/v1/chart // Одговор: release-level chart data { "generatedAt": "2026-04-08T16:30:17Z", "totalReleases": 2603, "releases": [ { "releaseId": "...", "popularity": 100, "followers": 4598, "youtubeViews": 121879 } ] }
GET /api/v1/chart/genres
Жанровски групи за листите (рап, електроника, рок, итн.).
GET /api/v1/chart/history/:week
Историја на листата за одредена недела. Формат: 2026-W14.
// Пример: листата за недела 14 од 2026 GET /api/v1/chart/history/2026-W14

Вести

GET /api/v1/articles
Статии од македонски медиуми поврзани со артисти од базата.
ПараметарОпис
qПребарување (по наслов или опис)
sourceФилтер по извор (пр. mono-ton)
fromПочетен датум
toКраен датум
// Пример: вести од mono-ton за април 2026 GET /api/v1/articles?source=mono-ton&from=2026-04-01 // Одговор: { "total": 5, "limit": 50, "offset": 0, "data": [ { "title": "SCOTT MCCLOUD", "link": "https://...", "date": "2026-04-20", "source": "mono-ton" } ] }

Кустоси

GET /api/v1/curators
Листа на кустоси со нивните плејлисти и линкови.
GET /api/v1/curators // Одговор: [ { "name": "Теа Трајковска", "image": "https://...", "links": ["https://instagram.com/..."], "playlists": ["https://open.spotify.com/..."] } ]

Директен пристап до JSON

Ако не ви треба филтрирање — податоците може директно да ги преземете:

ДатотекаОпис
bands.json Целосна база на артисти
events.json Сите настани
releases.json Сите изданија со YouTube видеа
genres.json Листа на жанрови
chart-data.json Тековни податоци за листата
chart-genres.json Жанровски групи за листите
articles.json Вести (~21,000+ статии)
curators.json Кустоси

Примери

JavaScript (fetch)

// Земи ги сите артисти од Скопје со жанр Rap const resp = await fetch('https://toplista-api.deeeeelay.workers.dev/api/v1/artists?city=Скопје&genre=Rap'); const { data, total } = await resp.json(); console.log(`Најдени: ${total} артисти`);

Python

import requests resp = requests.get('https://toplista-api.deeeeelay.workers.dev/api/v1/events', params={'upcoming': 'true'}) events = resp.json()['data'] for e in events: print(f"{e['date']} — {e['title']}")

curl

curl "https://toplista-api.deeeeelay.workers.dev/api/v1/releases?type=single&limit=5"

Грешки

КодОпис

429Премногу барања (макс. 60/мин)
502Податоците не се достапни
