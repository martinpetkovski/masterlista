ТопЛиста.мк API v1

Преглед

Јавен REST API за пристап до податоците на ТопЛиста.мк. Сите одговори се во JSON формат. Не е потребна автентикација.

Базен URL: https://api.toplista.mk/api/v1

  • Метод: само GET
  • Формат: JSON
  • Лимит: 60 барања во минута по IP
  • Пагинација: limit и offset на list endpoints
  • Кеш: 5 минути

Пагинација

Ендпоинтите што враќаат листи враќаат објект со total, limit, offset и data.

Параметар Опис Стандардно
limit Број на резултати по одговор 50
offset Почетна позиција за pagination 0

Ендпоинти

GET /api/v1
Основни информации за API-то и листа на достапни ендпоинти.
GET /api/v1/artists
Листа на артисти од базата. Поддржува q, city, genre, confirmed, limit, offset.
GET /api/v1/artists/:slug
Поединечен артист по slug. Пример: /api/v1/artists/mizar.
GET /api/v1/events
Настани. Поддржува from, to, artist, upcoming=true, limit, offset.
GET /api/v1/releases
Изданија. Поддржува artist, type, from, to, limit, offset.
GET /api/v1/genres
Листа на сите жанрови во базата.
GET /api/v1/chart
Тековни chart податоци по release.
GET /api/v1/chart/genres
Жанровски групи што ги користи chart логиката.
GET /api/v1/chart/history/:week
Историја по недела. Пример: /api/v1/chart/history/2026-W14.
GET /api/v1/articles
Вести и статии. Поддржува q, source, from, to, limit, offset.
GET /api/v1/curators
Листа на кустоси со линкови и playlists.

Примери

JavaScript

const response = await fetch('https://api.toplista.mk/api/v1/artists?city=Скопје&genre=Rap'); const result = await response.json(); console.log(result.total); console.log(result.data);

Python

import requests response = requests.get( 'https://api.toplista.mk/api/v1/events', params={'upcoming': 'true', 'limit': 5} ) data = response.json() print(data['total'])

curl

curl "https://api.toplista.mk/api/v1/releases?type=single&limit=5"

Директни JSON датотеки

Ако не ви треба query API, податоците се достапни и како статички JSON датотеки:

Датотека Опис
bands.json База на артисти
events.json Настани
releases.json Изданија
genres.json Жанрови
chart-data.json Тековни chart податоци
chart-genres.json Chart genre mapping
articles.json Вести
curators.json Кустоси

Грешки

Код Опис
404 Непостоечки endpoint или ресурс
405 Метод што не е дозволен
429 Надминат rate limit
502 Изворните JSON податоци моментално не се достапни
